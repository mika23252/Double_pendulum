# Double Pendulum

Проект на C++ для численного моделирования плоского двойного маятника с двумя грузами и двумя стержнями фиксированной длины. Программа рассчитывает координаты и скорости грузов во времени, а отдельный Python-скрипт строит графики и анимацию движения.

## Модель и параметры

Параметры задаются в `progalab1/euler_method_lab1.cpp`:

| Параметр | Значение |
| --- | ---: |
| Массы грузов M1, M2 | 1.0 |
| Длины стержней L1, L2 | 1.0 |
| Ускорение свободного падения G | 9.80665 |
| Шаг по времени dt | 0.0005 |
| Время моделирования t_stop | 10.0 |
| Начальные углы | pi / 2 для обоих стержней |

Начальное состояние и параметры можно изменить в исходном файле. Внешний ввод параметров при запуске не предусмотрен.

## Вычисления

Состояние системы хранится в декартовых координатах и скоростях двух грузов. На каждом временном шаге вычисляются натяжения стержней, а для выполнения кинематических ограничений решается система нелинейных уравнений с помощью `fsolve`.

Результаты выводятся в стандартный поток вывода. Каждая строка содержит девять чисел в следующем порядке:

` t x1 y1 x2 y2 vx1 vy1 vx2 vy2 `

## Сборка и запуск

### C++-программа

1. Откройте `progalab1.sln` в Visual Studio.
2. Выберите конфигурацию и платформу, доступные в вашей среде, и соберите проект `progalab1`.
3. Запустите полученный исполняемый файл, перенаправив стандартный вывод в `progalab1/out.txt`.

Например, для конфигурации `x64 Release` из корневой папки репозитория:

```powershell
.\x64\Release\progalab1.exe > .\progalab1\out.txt
```

Если выбрана другая конфигурация, замените путь к исполняемому файлу на фактический путь из Visual Studio.

**Настройки сборки зависят от локального окружения.** В конфигурации `Debug|Win32` файл проекта содержит пути к CMINPACK в каталоге `D:\cminpack-1.3.11` и ссылку на `cminpack_s.lib`. При использовании этой конфигурации проверьте и при необходимости измените пути в свойствах проекта.

### Визуализация на Python

Для визуализации нужны Python 3, NumPy и Matplotlib:

```bash
python -m pip install numpy matplotlib
```

После создания `out.txt` запустите скрипт из каталога `progalab1`:

```bash
cd progalab1
python parse.py
```

Скрипт строит графики координат и длин стержней во времени, а также анимацию движения маятника.

## Примечания

- `parse.py` ожидает файл `out.txt` в текущем рабочем каталоге.
- Программа моделирования выводит данные в консоль; файл `out.txt` создаётся перенаправлением вывода, а не отдельной операцией записи из C++-кода.
- Каталоги `Debug`, `Release` и `x64` содержат результаты сборки, а не исходный код проекта.

# Double Pendulum

Проект на C++ для численного моделирования плоского двойного маятника с двумя грузами и двумя стержнями фиксированной длины. Программа рассчитывает координаты и скорости грузов во времени, а отдельный Python-скрипт строит графики и анимацию движения.

## Вывод уравнений движения

Грузы связаны нерастяжимыми невесомыми нитями (жесткими стержнями).<br>
Вводится декартова система координат с началом отсчета в точке крепления верхнего стержня.

### Переменные

| Переменная | Обозначение |
| --- | ---: |
| Координаты грузов |  x<sub>1</sub>, x<sub>2</sub>, y<sub>1</sub>, y<sub>2</sub>  |
| Длины стержней | l<sub>1</sub>, l<sub>2</sub> |
| Массы грузов | m<sub>1</sub>, m<sub>2</sub> |
| Углы между стержнями и вертикалью | θ<sub>1</sub>, θ<sub>2</sub> |

$$
x_1 = l_1 \sin \theta_1,
$$

$$
x_2 = l_1 \sin \theta_1 + l_2 \sin \theta_2,
$$

$$
y_1 = -l_1 \cos \theta_1,
$$

$$
y_2 = -l_1 \cos \theta_1 - l_2 \cos \theta_2,
$$

где

$$
\theta_1 = \theta_1(t), \quad \theta_2 = \theta_2(t).
$$

Составим систему уравнений:

$$
\begin{cases}
\ddot{x}_1 = -\frac{x_1}{l_1 m_1} T_1 + \frac{x_2 - x_1}{l_2 m_1} T_2, \\
\ddot{y}_1 = -\frac{y_1}{l_1 m_1} T_1 + \frac{y_2 - y_1}{l_2 m_1} T_2 - g, \\
\ddot{x}_2 = -\frac{x_2 - x_1}{l_2 m_2} T_2, \\
\ddot{y}_2 = -\frac{y_2 - y_1}{l_2 m_2} T_2 - g, \\
x_1^2 + y_1^2 = l_1^2, \\
(x_2 - x_1)^2 + (y_2 - y_1)^2 = l_2^2.
\end{cases}
\qquad (1)
$$

В системе (1) записаны 4 дифференциальных уравнения и 2 алгебраических.

Для вычисления сил натяжения $$T_1$$ и $$T_2$$ дважды продифференцируем алгебраические уравнения и объединим их в систему:

$$
\begin{cases}
\ddot{x}_1 x_1 + \dot{x}_1^2 + \ddot{y}_1 y_1 + \dot{y}_1^2 = 0, \\
(\dot{x}_2 - \dot{x}_1)^2 + (x_2 - x_1)(\ddot{x}_2 - \ddot{x}_1) + (\dot{y}_2 - \dot{y}_1)^2 + (y_2 - y_1)(\ddot{y}_2 - \ddot{y}_1) = 0.
\end{cases}
$$

Подставляя выражения для вторых производных, получаем СЛАУ относительно $$T_1$$ и $$T_2$$:

$$
\begin{cases}
-\frac{y_1^2 - x_1^2}{l_1 m_1} T_1 + \frac{(x_2 - x_1)x_1 + (y_2 - y_1)y_1}{l_2 m_1} T_2 = g y_1 - v_{y_1}^2 - v_{x_1}^2, \\
\frac{(x_2 - x_1)x_1 + (y_2 - y_1)y_1}{l_1 m_1} T_1 + \frac{(y_2 - y_1)^2 + (x_2 - x_1)^2}{l_2} \left( \frac{1}{m_1} + \frac{1}{m_2} \right) T_2 = -(v_{x_2} - v_{x_1})^2 - (v_{y_2} - v_{y_1})^2.
\end{cases}
\qquad (2)
$$

## Описание численной схемы

В качестве метода численного интегрирования используется неявный метод Эйлера.

Система уравнений относительно координат и скоростей по оси \(Ox\):

$$
\begin{cases}
v_{x_1}^i = v_{x_1}^{i-1} + h \left( -\frac{x_1^i}{l_1 m_1} T_1 + \frac{x_2^i - x_1^i}{l_2 m_1} T_2 \right), \\
x_1^i = x_1^{i-1} + h v_{x_1}^i, \\
v_{x_2}^i = v_{x_2}^{i-1} - \frac{x_2^i - x_1^i}{l_2 m_2} T_2 h, \\
x_2^i = x_2^{i-1} + h v_{x_2}^i,
\end{cases}
$$

где $$h$$ — шаг интегрирования.

Преобразовывая систему, получаем СЛАУ относительно $$i$$-х компонент:

$$
\begin{cases}
\left[ \frac{h T_2}{l_2 m_1} + \frac{h T_1}{l_1 m_1} \right] x_1^i - \frac{h T_2}{l_2 m_1} x_2^i + v_{x_1}^i = v_{x_1}^{i-1}, \\
x_1^i - h v_{x_1}^i = x_1^{i-1}, \\
-\frac{h T_2}{l_2 m_2} x_1^i + \frac{h T_2}{l_2 m_2} x_2^i + v_{x_2}^i = v_{x_2}^{i-1}, \\
x_2^i - h v_{x_2}^i = x_2^{i-1}.
\end{cases}
\qquad (3)
$$

Аналогично для системы с уравнениями относительно координат и скоростей по оси $$Oy$$:

$$
\begin{cases}
\left[ \frac{h T_2}{l_2 m_1} + \frac{h T_1}{l_1 m_1} \right] y_1^i - \frac{h T_2}{l_2 m_1} y_2^i + v_{y_1}^i = v_{y_1}^{i-1} - h g, \\
y_1^i - h v_{y_1}^i = y_1^{i-1}, \\
-\frac{h T_2}{l_2 m_2} y_1^i + \frac{h T_2}{l_2 m_2} y_2^i + v_{y_2}^i = v_{y_2}^{i-1} - h g, \\
y_2^i - h v_{y_2}^i = y_2^{i-1}.
\end{cases}
\qquad(4)
$$

## Модель и параметры

Параметры задаются в `progalab1/euler_method_lab1.cpp`:

| Параметр | Значение |
| --- | ---: |
| Массы грузов M1, M2 | 1.0 |
| Длины стержней L1, L2 | 1.0 |
| Ускорение свободного падения G | 9.80665 |
| Шаг по времени dt | 0.0005 |
| Время моделирования t_stop | 10.0 |
| Начальные углы | pi / 2 для обоих стержней |

Начальное состояние и параметры можно изменить в исходном файле. Внешний ввод параметров при запуске не предусмотрен.

## Вычисления

Состояние системы хранится в декартовых координатах и скоростях двух грузов. На каждом временном шаге вычисляются натяжения стержней, а для выполнения кинематических ограничений решается система нелинейных уравнений с помощью `fsolve`.

Результаты выводятся в стандартный поток вывода. Каждая строка содержит девять чисел в следующем порядке:

` t x1 y1 x2 y2 vx1 vy1 vx2 vy2 `

## Сборка и запуск

### C++-программа

1. Откройте `progalab1.sln` в Visual Studio.
2. Выберите конфигурацию и платформу, доступные в вашей среде, и соберите проект `progalab1`.
3. Запустите полученный исполняемый файл, перенаправив стандартный вывод в `progalab1/out.txt`.

Например, для конфигурации `x64 Release` из корневой папки репозитория:

```powershell
.\x64\Release\progalab1.exe > .\progalab1\out.txt
```

Если выбрана другая конфигурация, замените путь к исполняемому файлу на фактический путь из Visual Studio.

**Настройки сборки зависят от локального окружения.** В конфигурации `Debug|Win32` файл проекта содержит пути к CMINPACK в каталоге `D:\cminpack-1.3.11` и ссылку на `cminpack_s.lib`. При использовании этой конфигурации проверьте и при необходимости измените пути в свойствах проекта.

### Визуализация на Python

Для визуализации нужны Python 3, NumPy и Matplotlib:

```bash
python -m pip install numpy matplotlib
```

После создания `out.txt` запустите скрипт из каталога `progalab1`:

```bash
cd progalab1
python parse.py
```

Скрипт строит графики координат и длин стержней во времени, а также анимацию движения маятника.

## Примечания

- `parse.py` ожидает файл `out.txt` в текущем рабочем каталоге.
- Программа моделирования выводит данные в консоль; файл `out.txt` создаётся перенаправлением вывода, а не отдельной операцией записи из C++-кода.
- Каталоги `Debug`, `Release` и `x64` содержат результаты сборки, а не исходный код проекта.
